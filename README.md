# Simivoz App

Proyecto web estático con HTML, CSS y JavaScript modular.

## Estructura

```
simivoz_app/
├── index.html           # Home
├── nosotros.html        # Página Nosotros
├── contacto.html        # Página Contacto
├── css/
│   ├── main.css         # Central (importa el resto)
│   ├── variables.css    # Variables globales
│   └── componentes/     # Navbar, footer, etc.
├── js/
│   ├── main.js          # Entry point (ES Module)
│   ├── modulos/         # api.js, utils.js
│   └── componentes/     # carrusel.js
└── assets/
    ├── img/
    ├── video/
    └── fonts/
```
